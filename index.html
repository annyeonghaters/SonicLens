How to Host on GitHub Pages

  1. Rename sonic_lens.html to index.html.
  2. Download all 4 companion files above (manifest.webmanifest, sw.js, icon-192.png, and icon-512.png).
  3. Upload index.html and the 4 files together into the root folder of your public GitHub repository and commit.
  4. In your repo, go to Settings → Pages, set Branch to main (/ (root)), and save.
  5. Open your live https://username.github.io/repo/ URL in Android Chrome and tap Install in the header (or Chrome's ⋮ → Add to Home screen).
